## 关于 AI 的使用

考核通知明确允许技术报告中借助 AI。本仓库的实际做法：

- **AI 负责"怎么做"** —— 具体命令、语法、报错含义、方案取舍；
- **本人负责"做什么"** —— 判断这一步是否必要、结论是否成立、结果能否复现。

落到仓库里：

- `基础题/` 第 1~6 关是逐条自己查证的原始记录，**连打错的命令和失败输出都原样留着**
  （例如 `bash: exam: command not found`、把修好的输入文件误当成 `flag`）。
- HPC 第 3 关报告的第 6 节「复盘」由本人撰写，其中记录了**哪些 AI 建议被采用、
  哪些被否定**，以及对测量环境问题的判断过程。
- 报告中凡是模型推算而非实测的数值（例如 HPC 第 2 关的"有效带宽"），
  都已在对应章节标注为模型值。
