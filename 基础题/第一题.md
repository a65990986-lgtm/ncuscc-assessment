一开始pwd看看在哪?
```
/workspace
```

ls -la看看有什么
```
drwxr-xr-x 4 ubuntu ubuntu 4096 Oct 11 08:03 .
drwxr-xr-x 1 root   root   4096 Oct 11 08:03 ..
```

用find . -type f  去找文件.find默认就是递归的.用ls只能找一层,那样太慢了,而且麻烦又容易出错
```
./exam
./input.bin
./cabinet/key.txt
```

得到
```console
用法：exam [-h] -e 密钥

使用密钥处理 /workspace/input，将结果写入 /workspace/output。

选项:
  -h, --help  显示帮助并退出
  -e 密钥       指定非空 ASCII 密钥

诊断日志：/var/log/ncuscc/exam.log。退出码：0 表示成功，1 表示处理失败，2 表示参数错误或无法写入日志。
```

通过这个看看key密钥里面是什么cat ./cabinet/key.txt
发现是MOON

按照help的说法,我们应该./exam -e MOON
居然这样告诉我
```console
 /workspace/input 必须是普通文件，不能是符号链接
```
按照DSH的说法,是出题人写死了只能用/workspace/input,因此我们尝试用 cp ./input.bin ./input

为什么用cp?dsh的说法是"程序要逐字节比较结果，而符号链接指向的目标可以被替换。为了排除这种不确定性，程序要求必须是实打实的普通文件。cp 复制出真文件，ln -s 只建路标。用 cp 的另一个好处：它在文件层面直接复制字节，不需要「读出来再写回去」这种经过人工/文本处理的方式，不会改变内容。"

用ls .检查一下
发现是cabinet  exam  input  input.bin  logs
没问题就下一步

```console
./exam -e MOON
```
检查一下返回状态,是0就没问题,非零就有问题."正确的情况只有一种,错误的情况有无数种"
完成之后exam一声不吭,所以要检查一下返回状态.dsh补充:"$? 只保存最近一条命令的退出码，必须紧跟着查，中间不能插别的命令。"
```console
echo $?
0
```

用ls -l /workspace/output确认文件,没有这个文件终端会说没找到,这里我知道了这个是多大了,方便后面题目说"逐字节相同"

```console
得到-rw-r--r-- 1 ubuntu ubuntu 16 Oct 11 08:05 /workspace/output
```

mv output flag用mv改名成题目要求的flag.

dsh这里补充"为什么必须用 mv，不能 cat 看一遍再手抄：文件是二进制，手抄或复制粘贴哪怕多一个换行，逐字节比较就不相等了。题目提示 3 说的"文件管理命令可以帮助你保持二进制内容不变"就是这个意思。"

wc -c flag按照要求自查字节数
