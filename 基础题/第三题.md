这里有个密钥,看看里面是什么


题目说日志在这个地址,但是没找到.我的推断:日志文件还不存在,因为它还没被创建
```console
bash-5.2$ cat /var/log/ncuscc/exam.log
cat: /var/log/ncuscc/exam.log: No such file or directory
```

运行之前看看exam的help
```console
bash-5.2$ ./exam --help
用法：exam [-h] -e 密钥

使用密钥处理 /workspace/input，将结果写入 /workspace/output。

选项:
  -h, --help  显示帮助并退出
  -e 密钥       指定非空 ASCII 密钥

```

用密钥NOVA运行exam
```console
bash-5.2$ ./exam -e NOVA
exam: /workspace/input 必须是普通文件，不能是符号链接
```

好吧,程序要的是input,名字对不上不给跑,改了
```console
bash-5.2$ mv input.txt input
```

运行之后告诉我信息
```console
bash-5.2$ ./exam -e NOVA
exam: 输入字节数必须是密钥字节数的整数倍（输入 19 字节，密钥 4 字节）
```

现在去看看exam.log,日志生成了和前面exam的提示一样
```console
bash-5.2$ cat /var/log/ncuscc/exam.log
exit=1 error=/workspace/input 必须是普通文件，不能是符号链接
exit=1 error=输入字节数必须是密钥字节数的整数倍（输入 19 字节，密钥 4 字节）
```

用cat -A input来看看input里面是什么.dsh告诉我 cat -A 的 -A可以"把看不见的字符显示出来：行尾的换行显示成 $，Tab 显示成 ^I"
```console
bash-5.2$ cat -A input
REPAIR THIS SIGNAL$
```

用 sed 在行尾插一个空格.格式是s/旧/新/.我们按照题目的要求加一个空格.
不用编辑器的原因：nano/vim 保存时可能改动换行符、或在末尾多补一个换行，而题目要求"其他字节必须保留"。用 sed 是可控的，改了什么一眼能看见。
```console
bash-5.2$ sed 's/SIGNAL$/SIGNAL /' input > input.fixed
```

看看input和input.fixed是多少个字节,看看数量有没有被改
```console
bash-5.2$ wc -c input input.fixed
19 input
20 input.fixed
39 total
```

看看具体的字符是不是我们想要的那样,行末会自动补一个$,所以空格之后有$
```console
bash-5.2$ cat -A input.fixed
REPAIR THIS SIGNAL $
```

这里我错了,把修好的输入文件当成了 flag.漏跑了 exam.但是题目说提交 /workspace/flag，内容须与按上述限制修复输入后生成的结果逐字节相同； 无需提交修改后的输入文件。
```console
bash-5.2$ cp input.fixed /workspace/flag
bash-5.2$ ls -l
total 10
-rwxr-xr-x 1 ubuntu ubuntu 3405 Oct 11 11:45 exam
-rw-r--r-- 1 ubuntu ubuntu   20 Oct 11 11:52 flag
-rw-r--r-- 1 ubuntu ubuntu   19 Oct 11 11:45 input
-rw-r--r-- 1 ubuntu ubuntu   20 Oct 11 11:50 input.fixed
-rw-r--r-- 1 ubuntu ubuntu    5 Oct 11 11:45 key.txt
drwxr-xr-x 2 ubuntu ubuntu 4096 Oct 11 11:47 logs
bash-5.2$ wc -c input flag
19 input
20 flag
39 total
bash-5.2$ cat -A flag
REPAIR THIS SIGNAL $
bash-5.2$ 
```

dsh提醒我之后,改了.把改好的东西给input一份
```console
bash-5.2$ cp input.fixed input
```

看看数量对的上吗
```console
bash-5.2$ wc -c input
20 input
```

运行
```console
bash-5.2$ /workspace/exam -e NOVA
```

看看退出状态是什么,0就没问题
```console
bash-5.2$ echo $?
0
```

给flag复制过去exam生成的东西
```console
bash-5.2$ mv /workspace/output /workspace/flag
```

看看数量对吗
```console
bash-5.2$ wc -c /workspace/flag
20 /workspace/flag
```

看看我们的flag里面是什么
```console
bash-5.2$ cat -A /workspace/flag
^\$
```

这次是乱码，但这是正确的——flag 是 exam 处理后的二进制结果，不是文本，本来就不该看得懂.有很多控制字符,这里就不展示了,因为可能影响排版

看看日志,最后是exit=0 bytes=20,说明成功了
```console
bash-5.2$ cat /var/log/ncuscc/exam.log
exit=1 error=/workspace/input 必须是普通文件，不能是符号链接
exit=1 error=输入字节数必须是密钥字节数的整数倍（输入 19 字节，密钥 4 字节）
exit=0 bytes=20
bash-5.2$ 
```


退出码是0,结果文件字节数是20的普通文件,日志里面exit=0 bytes=20
都说明没问题,可以交了


总结/下次注意的:
日志文件不存在？            --help 说是"诊断日志"，说明是程序运行时写的.先跑一次试试
要看到看不见的字符          cat -A
怎么改才不破坏其他字节？     编辑器会偷偷改换行,要用可控工具     sed 's/SIGNAL$/SIGNAL /'
改对了吗？                 数量（wc -c）+ 位置（cat -A）两个都要验
交什么？                   修好的输入是原料，要交的是处理结果
